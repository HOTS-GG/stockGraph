# 📈 주식 차트 패턴 학습실 (stockGraph)

주식 그래프의 움직임과 패턴을 학습하기 위한 교육용 웹사이트입니다.
**투자자산운용사 자격증 교재의 기술적 분석 파트**를 참고하여 구성했습니다.

## 학습 내용

| 단원 | 내용 |
|---|---|
| 개요 | 기술적 분석의 3가지 기본 가정, 기본적 분석과의 비교, 다우 이론(강세·약세시장 3국면) |
| 캔들차트 | 캔들 구조(시가·고가·저가·종가), 망치형·교수형·유성형·십자형, 장악형·샛별형·석별형·적삼병·흑삼병 |
| 추세·지지/저항 | 추세선 긋는 법, 지지선·저항선, 역할 전환(되돌림) |
| 이동평균선 | 골든/데드 크로스, 정배열·역배열, 이격도, 그랜빌의 8법칙 |
| 반전형 패턴 | 헤드앤숄더(삼봉형), 이중천장·이중바닥, 원형, V자형 |
| 지속형 패턴 | 삼각형(대칭·상승·하락), 직사각형, 깃발형, 페넌트형, 쐐기형 |
| 갭 이론 | 보통갭 → 돌파갭 → 급진갭 → 소멸갭, 섬꼴반전 |
| 보조지표 | 거래량, 볼린저 밴드, RSI, MACD, 스토캐스틱, OBV, 엘리엇 파동 |
| 패턴 퀴즈 | 랜덤 생성 차트를 보고 패턴 이름 맞히기 (정답 공개 시 주석 표시) |

## 특징

- **의존성 없음** — 순수 HTML/CSS/JS + Canvas. 빌드 과정 없이 바로 열립니다.
- **랜덤 생성 차트** — 모든 예시 차트는 열 때마다 조금씩 다르게 생성되어, "다시 그리기" 버튼으로 같은 패턴의 다양한 변형을 반복 학습할 수 있습니다.
- **한국식 캔들 색상** — 상승(양봉) 빨강, 하락(음봉) 파랑.
- **보조지표는 실제 계산** — RSI, MACD, 볼린저 밴드, 스토캐스틱, OBV는 생성된 가격 데이터로부터 실제 공식으로 계산해 그립니다.

## 실행 방법

`index.html`을 브라우저에서 열면 됩니다. 또는 간단한 서버로:

```bash
python3 -m http.server 8000
```

## GitHub Pages 배포

저장소 Settings → Pages → Branch를 `main`(root)으로 지정하면
`https://hots-gg.github.io/stockGraph/` 에서 접속할 수 있습니다.

## 파일 구성

```
index.html        # 전체 학습 내용 (탭 구조)
css/style.css     # 스타일
js/chart.js       # 캔들차트 렌더러 (Canvas, 의존성 없음)
js/patterns.js    # 패턴별 차트 데이터 생성기 (랜덤 변형)
js/quiz.js        # 패턴 퀴즈
js/main.js        # 탭 전환·차트 초기화
```

> ⚠️ 교육용 학습 자료입니다. 차트는 학습을 위해 생성된 가상 데이터이며, 실제 투자 판단의 근거가 될 수 없습니다.
